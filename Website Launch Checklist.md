# Website Launch Checklist  
A complete step-by-step guide to ensure your website is ready for a smooth, successful launch.

---

# ✅ 1. Technical Setup

### Domain & Hosting
- Domain pointing correctly (A records, AAAA, CNAME)
- SSL installed and forcing HTTPS
- Hosting environment stable and tested
- PHP version updated (8.1+ ideally)
- Email sending configured (SMTP or transactional)

### CMS / Platform
- CMS updated (WordPress, Shopify, etc.)
- Theme and plugins updated
- Remove unused plugins/themes
- Delete demo content

---

# ✅ 2. Design & UX Review
- Typography consistent across all pages
- Button styles consistent (rounded, colours, hover)
- Spacing and padding uniform
- Branding accurate (logos, colours, icons)
- No placeholder text remaining
- All images high quality and correctly sized
- Favicon added

---

# ✅ 3. Mobile & Responsive Testing
Test on:
- Desktop  
- Tablet  
- Mobile (iOS + Android)

Check:
- Menu & mobile nav  
- Buttons and tap targets  
- Layout integrity  
- Sliders, galleries, videos  
- Forms  
- Font sizes  
- CLS issues (layout shifting)

---

# ✅ 4. SEO Essentials

### Basic On-Page SEO
- Correct H1 on every page
- Proper H2/H3 structure
- Meta titles & descriptions
- Optimised slugs / URLs
- No duplicate content
- Schema markup where relevant

### Technical SEO
- XML sitemap generated
- Sitemap added to robots.txt
- Robots.txt clean (no accidental blocking)
- Canonical tags in place
- 404 page working and styled

---

# ✅ 5. Performance & Speed Testing
- Images compressed (WebP recommended)
- Lazy loading enabled
- Caching enabled
- Minified JS/CSS where possible
- Test speed on:
  - Google PageSpeed Insights  
  - GTMetrix  
  - WebPageTest  

Look for:
- LCP under 2.5s
- CLS stable
- Overall green score on mobile

---

# ✅ 6. Forms & Functionality
- Contact forms working
- Email notifications tested
- Confirmation messages correct
- Conditional logic correct (if applicable)
- Booking systems functioning
- Ecommerce cart, checkout, and payments working

---

# ✅ 7. Tracking & Analytics
- Google Analytics / GA4 installed
- Google Tag Manager installed
- Meta Pixel installed (if needed)
- Conversion events configured
- Test events using Tag Assistant
- Heatmap/recording tools configured (optional)

---

# ✅ 8. Security & Backups
- Security plugin installed (WordPress)
- Disable file editing inside dashboard
- Install firewall (if applicable)
- Auto-backups configured (daily or weekly)
- Change all admin passwords (final step)
- Create a restoration point before launch

---

# ✅ 9. Redirects & Final SEO Prep
- Redirect old URLs (301)
- Test internal linking
- Test external links
- Ensure no broken links
- Add the site to Google Search Console
- Submit sitemap

---

# ✅ 10. Final Pre-Launch Checklist
- Check every page manually
- Test across browsers (Chrome, Safari, Edge, Firefox)
- Proofread every page
- Check legal pages:
  - Privacy Policy  
  - Terms  
  - Cookie notice  
- Final signoff from client/team  
- Launch website  

---

# 🎉 Website Successfully Launched  
You’re ready to go live confidently with a professionally validated website!
