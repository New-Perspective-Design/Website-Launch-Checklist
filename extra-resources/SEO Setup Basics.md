# SEO Setup Basics for New Websites  
A simple foundational SEO guide to ensure a healthy start for any new website.

---

# 🔍 1. SEO Required Before Launch
- Unique meta title on every page
- Unique meta description on every page
- Correct H1 per page
- Proper H2/H3 structure
- Descriptive, clean URLs
- No index/no-follow removed (unless needed)
- Robots.txt checked for accidental blocks

---

# 🌐 2. Sitemap & Indexing
- XML sitemap generated
- Add sitemap to robots.txt
- Submit sitemap to Google Search Console
- Add site to Bing Webmaster Tools (optional)

---

# 🖼 3. Images & Media
- Images compressed (ideally WebP)
- File names descriptive (e.g., `wedding-venue-durban.jpg`)
- Alt text added to all images
- Lazy loading enabled

---

# ⚡ 4. Performance & Core Web Vitals
- LCP under 2.5s
- CLS stable (no shifting elements)
- JS/CSS minified where possible
- Browser caching enabled
- Lightweight plugins/theme choices

---

# 🔗 5. Link Structure
- Internal links added between relevant pages
- No broken links
- External links set to `rel="noopener"` or `rel="nofollow"` if needed

---

# 📝 6. Tracking & Analytics
- Google Analytics / GA4 installed
- Google Tag Manager installed
- Meta Pixel (if needed)
- Conversions tested

---

# 🛡 7. Security & Trust
- SSL installed correctly
- Mixed-content issues fixed
- Security plugin installed (WordPress)
- Admin URLs hidden (if applicable)
- Strong passwords enabled

---

## ✔ Final Notes
These steps give new websites a solid foundation for visibility, user experience, and long-term rankings.
